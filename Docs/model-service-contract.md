# Model Service Contract — Clinker Vision (Pipeline ⇆ Model)

**Version:** v0.4  
**Status:** Proposed by the pipeline team; pending model-owner sign-off.  
**Deployment:** Two Docker containers on one physical Ubuntu server.  
**Transport:** Local gRPC streaming over the private Docker Compose network; TLS is deferred for the localhost-only MVP.

## 1. MVP boundary

The pipeline pulls CAM-1 from the Dahua NVR, samples approximately one frame every two seconds, and sends a **full-frame JPEG** to the model. The pipeline performs no crop, ROI split, resize, or model-specific preprocessing.

The model container owns all dynamic cropping, resize, normalization, and inference in Python/OpenCV. Training and serving must use the same preprocessing path.

The MVP enables only the `GODET` target on `CAM-1`. The intended MVP findings are `CRACK` and `MISALIGNMENT`; the model remains responsible for returning the fault type it detects.

## 2. Responsibilities

**Pipeline provides:**

- Full-frame JPEG bytes from NVR CAM-1.
- `frame_id`, `camera_id`, `captured_at`, and monotonic `sequence_no`.
- Sampling, bounded queueing, drop-oldest backpressure, and pipeline-side thresholding.
- A persistent gRPC stream per inference worker.
- A mock model client/server for local integration tests.
- Logging with `frame_id`, `camera_id`, latency, and failure reason.

**Model provides:**

- A Docker image containing the Python/OpenCV inference service.
- The `clinkervision.inference.v1` gRPC service and final `.proto` file.
- Model-side crop, resize, normalization, and inference.
- Raw confidence values from 0.0 to 1.0; no thresholding inside the model.
- `observation_target` per detection, `model_version` on every response, and full-frame-relative boxes.
- A sample responder, test images, and CPU benchmark on the project server.

## 3. InferenceRequest

```proto
message InferenceRequest {
  string frame_id = 1;                         // UUID generated by pipeline
  string camera_id = 2;                        // CAM-1 in MVP
  bytes image_data = 3;                        // full-frame JPEG, not a crop
  google.protobuf.Timestamp captured_at = 4;   // source capture time
  uint64 sequence_no = 5;                      // monotonic per camera_id
}
```

| Field | Type | Rule |
|---|---|---|
| `frame_id` | string UUID | Generated by the pipeline and echoed by the model. |
| `camera_id` | string | `CAM-1` for MVP; future values `CAM-2` through `CAM-6`. |
| `image_data` | bytes | Full-frame JPEG. The pipeline sends no crop. |
| `captured_at` | timestamp | Original capture time, not send time. |
| `sequence_no` | uint64 | Monotonic per camera; useful for diagnosing drops/reordering. |

## 4. InferenceResponse

```proto
message InferenceResponse {
  string frame_id = 1;                        // echo of request
  repeated Detection detections = 2;          // empty = no qualifying finding
  map<string, float> scalar_measurements = 3; // future scalar targets
  string model_version = 4;                   // required build/weights ID
  google.protobuf.Timestamp processed_at = 5;
}

message Detection {
  ObservationTarget observation_target = 1;   // GODET in MVP
  FaultType fault_type = 2;                   // CRACK/MISALIGNMENT in MVP
  float confidence = 3;                       // raw 0.0–1.0
  BoundingBox bounding_box = 4;               // normalized full-frame box
}
```

| Field | Rule |
|---|---|
| `frame_id` | Must exactly match the request. |
| `detections` | Zero or more detections; empty is a successful normal result. |
| `scalar_measurements` | Reserved for future clinker-level measurements; not required in MVP. |
| `model_version` | Required on every response and stored with alerts. |
| `processed_at` | Model processing timestamp. |

`BoundingBox` uses `x`, `y`, `width`, and `height`, normalized from 0.0 to 1.0, top-left origin, relative to the **full input frame**. The pipeline validates and clamps values before overlay rendering.

## 5. Enums

```text
ObservationTarget: GODET | GALET | CLINKER_LEVEL
FaultType: DAMAGE | CRACK | WEAR | MISALIGNMENT | GAP |
           MISSING_GALET | SPILLAGE | LEVEL_THRESHOLD
```

Only `GODET`, `CRACK`, and `MISALIGNMENT` are required for the MVP.

## 6. Error behavior

| Condition | Pipeline behavior |
|---|---|
| `OK` with empty detections | Normal result; no alert. |
| `UNAVAILABLE` | Log model failure, discard the unprocessed frame, and start the dependency-failure timer. |
| `DEADLINE_EXCEEDED` | Log timeout and latency, discard the frame, and start the dependency-failure timer. |
| `INVALID_ARGUMENT` | Log `frame_id`/`camera_id`, discard the malformed frame, and do not retry that frame. |
| Invalid response | Log and discard the response; do not create an alert. |
| Required model dependency unavailable for five minutes | Stop the pipeline completely with a clear reason. |

The MVP does not persist frames for replay. Frames not processed by the model are considered lost to the vision pipeline; the NVR remains the source of recorded video.

## 7. Performance and handoff requirements

The model owner must provide:

1. A versioned Docker image, such as `clinker-model:2026.09.1`.
2. The final `.proto` file and a sample client/server invocation.
3. Required CPU, RAM, image dimensions, and JPEG quality.
4. Confirmation of training/inference preprocessing parity.
5. Average and worst-case CPU latency on the actual HP server, or a comparable CPU.
6. Test images and expected responses for godet crack and misalignment.
7. A mock or deterministic test mode for pipeline integration tests.

The initial pipeline threshold is `0.85` to prioritize low false-positive behavior. The threshold is configuration, not part of model inference.

## 8. Versioning and open items

- Incompatible proto changes require a package-version bump and review by both owners.
- `model_version` identifies weights/build and does not replace proto versioning.
- Confirm the exact model Docker image, proto, model benchmark, and test data before implementation sign-off.
- Confirm the final JPEG dimensions/quality after the first real CAM-1 capture test.
